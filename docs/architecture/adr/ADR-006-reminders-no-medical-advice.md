# ADR-006: No medical recommendations through reminders

- **Status:** Accepted
- **Context:** Default schedules and adherence language can appear to prescribe or judge treatment.
- **Decision:** Reminders refer only to user-created entries. HTP provides no fixed product schedules, treatment templates, dosage decisions, or continuation decisions.
- **Consequences:** Reminders are optional, editable, pausable, deletable, neutrally worded, and measured only as documentation activity.
- **Open points:** Notification channels and privacy-preserving defaults require implementation-specific review.
