# ADR-004: Photos private by default

- **Status:** Accepted
- **Context:** Photos can identify a person and reveal location, time, appearance, or health-related context.
- **Decision:** Photos are private by default. The first phase has no community, public profile, sharing, or public before-and-after gallery.
- **Consequences:** Storage and retrieval require restrictive access; unnecessary metadata is removed; no recognition, diagnosis, advertising, or general model training is allowed.
- **Open points:** Local-only, self-hosted, and optional cloud-storage implementations require separate review.
