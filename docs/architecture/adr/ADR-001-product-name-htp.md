# ADR-001: Product name HTP

- **Status:** Accepted
- **Context:** HTH originally described the handbook, while the future scope includes knowledge and private documentation functions.
- **Decision:** Use Hair Therapy Platform (HTP) for the future platform. Hair Therapy Handbook (HTH) remains its handbook and export format. The repository is not renamed in HTH-006.
- **Consequences:** Product documentation distinguishes HTP from HTH; existing repository history remains stable.
- **Open points:** Visual identity, domain, and legal name checks are outside this milestone.
