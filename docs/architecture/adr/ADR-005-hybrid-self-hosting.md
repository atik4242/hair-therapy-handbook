# ADR-005: Preserve hybrid and self-hosting capability

- **Status:** Proposed
- **Context:** Public knowledge benefits from central publication, while private records may benefit from local control or optional synchronisation.
- **Decision:** Keep a hybrid, local-first direction and self-hosting capability viable without committing to a production stack.
- **Consequences:** Interfaces and data formats should avoid unnecessary provider lock-in; multiple deployment modes increase testing and support work.
- **Open points:** Sync protocol, operational ownership, migration, backup, and support policy remain undecided.
