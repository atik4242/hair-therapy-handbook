# ADR-007: HTH as export format

- **Status:** Accepted
- **Context:** HTH already provides a reproducible, print-ready document foundation while HTP has a broader future scope.
- **Decision:** Hair Therapy Handbook remains the PDF/documentation export of HTP rather than the name of the entire future platform.
- **Consequences:** The export may combine eligible public modules and records explicitly selected by the requesting user; it must not introduce decision logic.
- **Open points:** Personal export schema, encryption, expiry, and multilingual layout need later ADRs.
