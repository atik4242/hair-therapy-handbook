# ADR-008: Trust before Revenue

- **Status:** Accepted
- **Context:** Monetisation pressure can conflict with privacy, clarity, and user control.
- **Decision:** User trust takes precedence over short-term revenue. HTP does not sell or market personal data, target advertising with personal or health-related data, share data with brokers, or use hidden trackers and dark patterns.
- **Consequences:** Monetisation proposals require explicit privacy and Core Principles review and must use models compatible with these constraints.
- **Open points:** A sustainable funding model is not selected in HTH-006.
