# Editorial Workflow

`Draft → Evidence Review → Medical/Subject Review → Language Review → Editorial Approval → Published → Periodic Review → Updated or Archived`

Publication requires traceable sources. Medically relevant material requires qualified subject review. Machine translations and AI-generated text must never be published without competent human review. Conflicts of interest must be disclosed, and corrections must retain a dated, versioned history.

The original-language author owns meaning; evidence reviewers check claims and provenance; subject reviewers check domain accuracy; language reviewers check each locale; editorial approval checks neutrality, accessibility, completeness, and the Core Principles gate. A reviewed translation becoming stale is marked `outdated`, not silently reused.
