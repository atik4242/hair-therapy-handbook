# Hair Therapy Platform Documentation

Hair Therapy Platform (HTP) is the proposed modular knowledge and private documentation platform. Hair Therapy Handbook (HTH) is its reproducible PDF and documentation export.

This documentation describes governance, architecture, privacy, internationalization, and editorial boundaries. It does not describe a production-ready health service: no accounts, hosted private storage, uploads, notifications, or cloud analysis are implemented.

## Core Principles

1. HTP informs — HTP does not diagnose.
2. HTP documents — HTP does not recommend therapy.
3. HTP reminds — HTP does not decide for the user.

Start with the [Platform Vision](PLATFORM_VISION.md), [Project Charter](PROJECT_CHARTER.md), [Platform Architecture](architecture/PLATFORM_ARCHITECTURE.md), and [Privacy Model](privacy/PRIVACY_MODEL.md).

Examples and mock-ups are non-medical demonstrations. Personal plans and reminders, if implemented in the future, are created and controlled entirely by the user.
